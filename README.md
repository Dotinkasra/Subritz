# Subritz

Subritzは、好きなYouTube動画で英語を学べるmacOSアプリです。動画に合わせて字幕と辞書が更新され、気になった単語や表現をその場で調べられます。

## 主な機能

- **字幕と辞書の同期**：発話中の単語・表現と意味をリアルタイムに表示。macOS標準辞書と英辞郎に対応します。
- **字幕から調べる**：マウスオーバー・クリックで単語を確認し、ドラッグで複数語の表現を選択。単語のダブルクリックで発話位置へ移動できます。
- **単語の読み上げ**：辞書カラムやお気に入りの単語詳細から、単語・表現をmacOS標準の英語音声で確認できます。音声の品質を選んで試聴することもできます。
- **字幕の検索・固定**：⌘Fで字幕全体を検索。Enterで次、Shift+Enterで前、Escで検索を閉じます。ピンボタンや字幕行の余白のダブルクリックでスクロール位置を固定できます。
- **イマージョンモード**：リアルタイム辞書の日本語を隠し、英語だけに集中できます。選択した単語やお気に入りの日本語説明はマスクをクリックすると確認できます。映像を隠して音声・字幕だけで学習することもできます。
- **履歴・お気に入り・しおり**：過去の動画や単語を保存し、出現位置から再生。お気に入りは登録日・件数で絞ってテキストやCSVに書き出せます。
- **Cambridge Dictionary**：「調べる」ボタンから英英辞書を表示。ブラウザやアプリ内ポップアップで開けます。
- **AI文法解析（任意）**：Codex CLIまたはOpenAI互換ローカルLLMで文脈を含めて解析し、S・V・O・Cなどを下線とラベルで表示。読み込み前にON/OFFを選べます。
- **リアルタイム音声認識**：Macの再生音と、選択したマイクの英語をAppleのSpeechAnalyzerで字幕化。入力元を切り替えながら、字幕の検索・固定や辞書を利用できます。
- **英語の視聴時間**：動画・音声認識で英語を聞いた時間を自動記録。年・月・週・日で切り替えて、動画と音声認識の内訳をグラフで振り返れます。

## 動作環境

- macOS 15以降（Intel / Apple Silicon）。
- リアルタイム音声認識のみ、macOS 26以降のSpeechTranscriber対応Macが必要です。初回に英語モデルをダウンロードします。実行ファイルやモデルのパス設定は不要です。
- インターネット接続と[yt-dlp](https://github.com/yt-dlp/yt-dlp)が必要です。導入方法は公式リポジトリを参照してください。
- 日本語辞書には、macOSの辞書アプリで「ウィズダム英和辞典 / ウィズダム和英辞典」をダウンロードするか、所有する英辞郎のテキストデータをインポートしてください。英辞郎のテキストデータは[BOOTH販売ページ](https://booth.pm/ja/items/777563)から入手できます。辞書データは同梱していません。
- AI文法解析を使う場合のみ、認証済みのCodex CLIまたはOpenAI互換ローカルLLMサーバーが必要です。

## インストール

1. [Releases](https://github.com/Dotinkasra/Subritz/releases)から最新のDMGファイルをダウンロードします。
2. DMGを開き、`Subritz.app`を`Applications`へドラッグします。
3. アプリケーションフォルダからSubritzを起動します。

配布アプリはad-hoc署名で、Appleの公証は行っていません。

## 使い方

1. 設定（⌘,）でyt-dlpと辞書を設定します。yt-dlpは通常、PATHやHomebrewの標準パスから自動検出します。AI文法解析を使う場合は解析サービスも設定します。
2. YouTube URLを入力し、AI文法解析のON/OFFを選んで「読み込む」を押します。英語の自動字幕がある動画が対象です。
3. 再生しながら字幕と辞書を確認します。字幕のクリックやドラッグで調べる対象を選択できます。
4. 辞書の星で単語をお気に入りに、シークバー左のしおりで再生位置を保存します。履歴・お気に入りから後で復習できます。

ライブラリの「タイムスタンプ」は動画ごとにまとまっています。動画を選ぶと詳細に保存した位置が再生時刻順で表示され、各時刻をクリックするとその位置から再生できます。タイムスタンプは個別に削除できます。

自動字幕やAI解析には誤りが含まれることがあります。語別時刻がない字幕では、発話位置への移動に推定時刻を使います。

動画・音声認識画面では、カラムの境界をドラッグして上下の高さ・左右の幅を調整できます。フッターの「表示調整」を開くと、字幕の文字サイズ・1行の文字数・行間をスライダーでリアルタイムに調整できます。文字サイズと文字数は中央が初期値です。文字数は目安で、単語の区切りとウィンドウ幅に合わせて折り返します。設定はYouTubeと音声認識で別々に記憶します。隣の回転矢印ボタンで確認画面を開き、「OK」を押すとカラム配置と両モードの字幕表示を初期値に戻せます。

音声認識の字幕は最新行に自動追従します。上へスクロールすると追従を一時解除して過去の字幕を読めます。最下部まで戻ると追従を再開します。ピン留めした場合は、ピン留めを解除するまでスクロール位置を固定します。

音声認識はトップ画面の「リアルタイム音声認識モード」から開始します。「Macの再生音」か「マイク」を選び、マイクの場合は入力デバイスを指定します。初回はmacOSの音声取得の許可が必要です。認識中も入力元の切り替え・一時停止・再開ができます。音声は保存しないため、認識字幕の過去の位置へ音声をシークすることはできません。

### 単語の発音を聞く

動画・音声認識画面の辞書カラム、または「単語のお気に入り」で単語を選び、スピーカーボタンを押すと、その単語や表現を英語で読み上げます。読み上げ中に同じボタンをもう一度押すと停止します。日本語の意味を隠したままでも利用できます。

設定（⌘,）の「単語の読み上げ」で音声の品質を選べます。「使用する英語音声」に表示された声が使われ、「試聴」で声の聞こえ方を確認できます。

| Subritzの設定 | macOSの声一覧での表示例 |
| --- | --- |
| 標準 | Ava |
| 拡張 | Ava（拡張） |
| プレミアム | Ava（プレミアム） |

標準の声には品質名の表記が付きません。

「拡張」「プレミアム」では、標準より高品質な音声を利用できます。選んだ品質の英語音声が未インストールの場合は、macOSの設定画面が開きます。次の手順で追加してください。

1. 「アクセシビリティ」→「リーダーと読み上げ」の「システムの声」の横にある詳細ボタンを開きます。macOSのバージョンによっては「読み上げコンテンツ」という名前です。
2. 声一覧で「英語」を選び、使いたい品質の声をダウンロードします。例えばプレミアムなら「Ava（プレミアム）」を選びます。追加にはインターネット接続と保存容量が必要で、容量は声の横に表示されます。
3. ダウンロードが完了したらSubritzへ戻ります。音声を自動で再検出するので、「使用する英語音声」を確認して試聴してください。

同じ品質の英語音声が複数ある場合、Subritzが使用する声を自動で選びます。選んだ品質の音声がない場合は、その品質の音声を追加するまで読み上げできません。

音声データはmacOSが管理し、ほかの対応アプリでも利用できます。すでに追加済みの音声をSubritz用にダウンロードし直す必要はありません。Subritzを削除しても音声は残り、音声の追加・削除はmacOSの設定から行えます。

### 英語の視聴時間を振り返る

画面右上の棒グラフボタン、または「ライブラリ」メニューの「英語の視聴時間」を開きます。「年」は月別、「月」は日別、「週」は曜日別、「日」は時間帯別のグラフです。前後の矢印で過去の期間を選べ、グラフのクリック・ドラッグで内訳を確認できます。

YouTubeでは、英語字幕がある区間を音声ありで再生している時間を記録します。一時停止・読み込み待ち・シークで飛ばした時間・プレーヤーのミュート中は含めません。映像を非表示にしたり、字幕をピン留めしたりしても記録します。倍速再生では動画の長さではなく実際に経過した時間を数え、同じ部分を聞き直した時間も加算します。

音声認識では、認識結果に含まれる英語の音声区間を記録します。無音で認識待ちになっている時間や、認識履歴を見直している時間は含めません。字幕・認識結果に基づく推定のため、実際に耳で聞いた時間と差が出る場合があります。

### バックアップと復元

設定（⌘,）の「バックアップ（iCloud Drive対応）」で保存先を選びます。iCloudに残す場合は、ファイル選択画面のサイドバーからiCloud Drive内のフォルダを指定してください。通常のフォルダや外付けドライブも選べます。

- 「自動バックアップを有効にする」をONにすると、変更内容をまとめて保存します。変更が続く間は約5分ごとに更新し、起動時・終了前にも保存します。自動保存は最新5件を保持します。
- 「今すぐバックアップ」で手動保存できます。手動で保存したファイルは自動削除しません。「保存先を開く」でファイルを確認できます。
- お気に入りの単語と登録時の辞書表示、視聴履歴、タイムスタンプ、学習時間、各種設定、カラムの幅・高さ・字幕の行間・文字サイズ・1行の文字数を保存します。動画・字幕・文法解析・音声認識のキャッシュ、辞書データ本体、macOS音声、APIキーは含みません。

「バックアップから復元…」でファイルを選ぶと、保存日時と内容を確認できます。「復元する」を押すと再生・音声認識を終了し、現在の学習データと設定を置き換えます。復元前の状態はこのMacに退避し、「復元前のバックアップを表示」から取り出せます。APIキーと、このMacで選んだバックアップ保存先・自動保存のON/OFFは変更しません。

iCloudへのアップロードはmacOSが行います。「最終保存」はファイルを書き出した日時で、転送完了日時ではありません。別のMacでは、実行ファイル・辞書・音声の準備や、マイクなどの再指定が必要になる場合があります。見つからないキャッシュ保存先は標準の保存先に戻します。複数のMacの変更を自動で統合する同期機能ではありません。

## データの保存

AI文法解析をONにすると、字幕のテキストを選択した解析サービスへ送信します。OFFの場合はAIへ送信しません。APIキーはmacOSのKeychainに保存します。

標準の保存先は`~/Library/Application Support/YouTubeEnglishStudy/`です。動画キャッシュの容量・保存先は設定で変更できます。キャッシュを削除しても履歴・お気に入り・辞書データは残ります。

音声認識は端末内で処理し、AI文法解析へ送信しません。認識した英文のキャッシュはメモリ内だけに保持します。上限は設定で変更でき、超過すると古い英文から削除します。認識画面を閉じてもアプリ起動中は「認識履歴」から見直せますが、アプリ終了時にすべて削除します。お気に入りに明示的に登録した単語は通常どおり保存します。

タイムスタンプは最大1000件で、上限を超えると古い記録から削除します。動画を閉じた位置は動画ごとに最新の1件を保持します。お気に入りを解除すると、その単語に関連付けた出現位置も削除されます。

英語の視聴時間は端末内に定期保存し、再生・認識の停止時にも保存します。動画キャッシュや音声認識キャッシュを削除しても記録は残ります。この記録に動画のURL・字幕・音声そのものは保存しません。

## ビルド

Swift 6以降とmacOS 26以降のSDKを含むXcodeまたはCommand Line Toolsを用意します。

```sh
git clone https://github.com/Dotinkasra/Subritz.git
cd Subritz
./scripts/build.sh
open dist/Subritz.app
```
