# Subritz

Subritzは、YouTube動画を見ながら字幕・辞書・文法を確認できるmacOS向けの英語学習アプリです。動画の再生に合わせて字幕と辞書が更新され、気になった単語や表現をその場で調べられます。

## 主な機能

- **動画と字幕の同期**：英語の自動字幕を取得し、現在行と前後の行を表示。過去・未来の字幕へスクロールでき、再生中は現在位置へ追従します。
- **字幕のスクロール固定**：字幕欄のピンボタン、または字幕行の余白のダブルクリックで自動スクロールを停止・再開できます。固定中の行をオレンジの枠で示し、動画と辞書の同期は続きます。
- **字幕内検索**：字幕欄の検索ボタンまたは⌘Fで動画全体の字幕を検索。入力に合わせて一致部分をハイライトし、Enterで次、Shift+Enterで前の結果へ移動できます。Escで検索を閉じると、スクロールを固定していない場合は再生位置への追従に戻ります。最後の検索文字列はアプリ起動中だけ保持し、再度開くと復元します。
- **リアルタイム辞書**：発話中の単語・表現と日本語の意味を大きく表示。macOSの辞書と、利用者がインポートした英辞郎のテキストに対応します。
- **複数語の表現**：`stacks up` → `stack up`のように、活用形を含む句動詞・熟語を辞書で照合します。
- **字幕からの辞書選択**：マウスを置くと詳細を表示し、クリックすると1語を固定。ドラッグで連続した複数語を指定できます。
- **発話位置への移動**：字幕の単語をダブルクリックすると、その単語の開始時刻へシークします。
- **AI文法解析**：Codex CLIまたはOpenAI互換のローカルLLMで文脈を含めて解析し、S・V・O・Cなどを色付きの下線とラベルで表示します。解析はバックグラウンドで進み、読み込み前にON/OFFを選べます。
- **イマージョンモード**：リアルタイム辞書を英単語・表現だけの表示へ即座に切り替え。選択した単語・表現の日本語語義と詳細定義は、お気に入りと同じマスクで隠します。マスクのクリックまたは表示ボタンで確認でき、選択を変えると再び非表示になります。
- **動画履歴・お気に入り**：最大100件の動画履歴をタイトル・サムネイル付きで表示。辞書の星から単語・表現を登録し、一覧で復習できます。お気に入りの日本語語義・詳細定義はグレーのマスクで初期状態では隠し、マスクのクリックまたは表示ボタンで確認できます。別の単語を選ぶと再び非表示になります。
- **お気に入りのエクスポート**：ライブラリの「単語のお気に入り」から、英単語をUTF-8のテキストまたはCSVに書き出します。日本語語義・辞書の詳細定義は含めません。メタデータなしでは単語だけを1行ずつ出力します。登録日の範囲・最新の件数を選べ、登録日時や動画・出現位置のメタデータも付けられます。
- **タイムスタンプ**：シークバー左のしおりから現在位置を保存。動画を閉じた位置とお気に入り単語の出現位置も記録し、ライブラリからその位置へ戻れます。同じ動画では確認後にシークし、別の動画では切り替えを確認します。
- **Cambridge Dictionary**：動画の辞書ヘッダーの「調べる」とお気に入りの詳細から、[公式の検索URL](https://dictionary.cambridge.org/freesearch.html)で英英辞書を開けます。字幕の空白区間などで単語がない場合は検索ページを開きます。「辞書を開く際のブラウザ」でシステムのデフォルト・インストール済みブラウザ・アプリ内ポップアップを選べます。ポップアップはサイトをそのまま表示し、ページの戻る・再読み込み・ブラウザで開く操作に対応します。
- **設定とキャッシュ**：設定の自動保存、解析結果のキャッシュ、キャッシュ容量・保存先の変更、日本語・英語のメニューに対応します。

## 動作環境

- macOS 15以降。
- 動画・字幕の読み込みに`yt-dlp`とインターネット接続が必要です。動画はYouTubeの埋め込みプレイヤーで再生します。
- 日本語の辞書表示には、macOSの辞書アプリで「ウィズダム英和辞典 / ウィズダム和英辞典」をダウンロードするか、所有する英辞郎テキストをインポートしてください。辞書データは同梱していません。macOS辞書は品詞・語義・例文を区別して表示します。
- AI文法解析を使う場合は、認証済みのCodex CLI、または`chat/completions`とJSON出力に対応したOpenAI互換ローカルLLMサーバーが必要です。AI文法解析をOFFにすれば、動画・字幕・辞書だけでも使えます。

## ビルド

Swift 6以降とmacOS SDKを含むXcodeまたはCommand Line Toolsを用意します。追加のSwift Package依存はありません。

```sh
git clone https://github.com/Dotinkasra/Subritz.git
cd Subritz
./scripts/build.sh
open dist/Subritz.app
```

`dist/Subritz.app`にアプリを生成し、ad-hoc署名します。配布用の公証（notarization）は行っていません。ビルドスクリプトは、macOS 26.5 SDKがCommand Line Toolsにある場合、そのSDKを選択します。Xcodeで`Package.swift`を開いて開発することもできます。

アプリアイコンは`scripts/Assets/AppIconSource.png`を元に、CoreGraphicsとmacOS標準の`iconutil`で角丸・透明余白付きの`.icns`を生成します。元画像や生成スクリプトを変更すると、次のビルドで自動更新されます。

## リリース

`v0.2.0`のようなバージョンタグをGitHubへプッシュすると、GitHub Actionsがテストを実行し、Apple Silicon・Intel対応の最適化ビルドを1つのDMGにまとめて[Releases](https://github.com/Dotinkasra/Subritz/releases)へ公開します。`v0.2.1-beta.1`のようなタグはプレリリースになります。

DMGには`Subritz.app`と`Applications`へのショートカットが入り、SHA-256チェックサムも公開します。アプリのバージョン番号はタグから設定します。アプリ・DMGの検証やテストに失敗した場合は公開しません。署名はad-hoc署名で、Developer ID署名・Appleの公証は行いません。yt-dlp・辞書データ・利用者の保存データは同梱しません。

```sh
git push origin main
git push origin v0.2.0
```

ローカルで同じDMGを作る場合は`./scripts/release.sh v0.2.0`を実行します。`dist/Subritz-v0.2.0-universal.dmg`とその`.sha256`ファイルを生成します。公開に使うワークフローは`.github/workflows/release.yml`で、リリースの作成にはGitHub標準の`GITHUB_TOKEN`を使います。追加のAPIキーは必要ありません。

## 使い方

1. 設定（⌘,）で`yt-dlp`の実行ファイルを確認します。通常はPATHやHomebrewの標準パスから自動検出します。
2. AI文法解析を使う場合は解析サービスを設定します。Codex CLIは事前にCLIで認証し、ローカルLLMはサーバーを起動してBase URLとモデル名を指定します。両サービスのモデル名は別々に保存します。
3. YouTube URLを入力し、「AI文法解析」のON/OFFを選んで「読み込む」を押します。英語の自動字幕がある動画が対象です。
4. 再生に合わせて字幕・辞書を確認します。字幕のクリック・ドラッグで調べる対象を指定し、「固定を解除」で自動表示へ戻せます。リアルタイムモードでは再生再開や次の単語への移動でも固定が解除されます。
5. 動画読み込み後の「イマージョンモード」で、日本語解説の表示を切り替えられます。「動画履歴」「お気に入り」から過去の動画・登録した語を開けます。
6. シークバー左のしおりボタンで現在位置を保存できます。ライブラリの「動画履歴」「タイムスタンプ」は、クリックで項目を選択し、選択中の項目をもう一度クリックすると開きます。詳細のボタンやお気に入りの「出現箇所」からも移動できます。

自動字幕の認識結果やAI解析には誤りが含まれることがあります。語別時刻がない字幕では、ダブルクリックの移動先に推定時刻を使います。

## データの保存

辞書検索はローカルで行います。AI文法解析をONにすると、字幕のテキストを選択した解析サービスへ渡します。OFFの場合、AIへの字幕送信と文法解析は行いません。

標準のデータ保存先は`~/Library/Application Support/YouTubeEnglishStudy/`です。動画キャッシュの保存先は設定で変更できます。履歴・お気に入り・タイムスタンプ・英辞郎データは動画キャッシュの削除とは独立して保持し、APIキーはmacOSのKeychainに保存します。

タイムスタンプは`library.sqlite`に最大1000件を保存し、上限を超えたら古い記録から削除します。しおりに動画ごとの件数制限はありません。動画を閉じる際の自動保存は「最後に開いた位置」として表示し、動画ごとに最新の1件だけを保持します。お気に入りの出現位置は登録・解除と一緒に保存・削除し、既存のお気に入りの出現位置も初回に移行します。アプリ終了時には記録の保存完了を待ちます。

## テスト

```sh
./scripts/test.sh
```

オフラインテストで字幕処理・再生同期・辞書・文法結果の検証・設定・履歴・お気に入りなどを確認します。外部サービスや実データを使う任意のテストは、必要な環境変数を指定した場合のみ実行します。インストール済みのウィズダム辞書を検証する場合は、`SUBRITZ_TEST_SYSTEM_DICTIONARY=1 ./scripts/test.sh --filter MacDictionaryTests` を実行します。

テスト用の辞書定義・例文・字幕は自作データです。実辞書や実動画の抜粋は同梱していません。

macOS辞書の構造化取得には、DictionaryServicesの非公開APIを動的に利用します。OS更新による互換性とApp Store配布への制約があります。APIや対応辞書を利用できない場合は公開APIの本文表示へ切り替え、本文から日本語の短義を推測しません。
