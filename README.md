# Subritz

Subritzは、好きなYouTube動画で英語を学べるmacOSアプリです。動画に合わせて字幕と辞書が更新され、気になった単語や表現をその場で調べられます。

## 主な機能

- **字幕と辞書の同期**：発話中の単語・表現と意味をリアルタイムに表示。macOS標準辞書と英辞郎に対応します。
- **字幕から調べる**：マウスオーバー・クリックで単語を確認し、ドラッグで複数語の表現を選択。単語のダブルクリックで発話位置へ移動できます。
- **字幕の検索・固定**：⌘Fで字幕全体を検索。Enterで次、Shift+Enterで前、Escで検索を閉じます。ピンボタンや字幕行の余白のダブルクリックでスクロール位置を固定できます。
- **イマージョンモード**：リアルタイム辞書の日本語を隠し、英語だけに集中できます。選択した単語やお気に入りの日本語説明はマスクをクリックすると確認できます。映像を隠して音声・字幕だけで学習することもできます。
- **履歴・お気に入り・しおり**：過去の動画や単語を保存し、出現位置から再生。お気に入りは登録日・件数で絞ってテキストやCSVに書き出せます。
- **Cambridge Dictionary**：「調べる」ボタンから英英辞書を表示。ブラウザやアプリ内ポップアップで開けます。
- **AI文法解析（任意）**：Codex CLIまたはOpenAI互換ローカルLLMで文脈を含めて解析し、S・V・O・Cなどを下線とラベルで表示。読み込み前にON/OFFを選べます。

## 動作環境

- macOS 15以降（Intel / Apple Silicon）。
- インターネット接続と[yt-dlp](https://github.com/yt-dlp/yt-dlp)が必要です。導入方法は公式リポジトリを参照してください。
- 日本語辞書には、macOSの辞書アプリで「ウィズダム英和辞典 / ウィズダム和英辞典」をダウンロードするか、所有する英辞郎のテキストデータをインポートしてください。英辞郎のテキストデータは[BOOTH販売ページ](https://booth.pm/ja/items/777563)から入手できます。辞書データは同梱していません。
- AI文法解析を使う場合のみ、認証済みのCodex CLIまたはOpenAI互換ローカルLLMサーバーが必要です。

## インストール

1. [Releases](https://github.com/Dotinkasra/Subritz/releases)から最新のDMGファイルをダウンロードします。
2. DMGを開き、`Subritz.app`を`Applications`へドラッグします。
3. アプリケーションフォルダからSubritzを起動します。

配布アプリはad-hoc署名で、Appleの公証は行っていません。

## 使い方

1. 設定（⌘,）でyt-dlpと辞書を設定します。yt-dlpは通常、PATHやHomebrewの標準パスから自動検出します。AI文法解析を使う場合は解析サービスも設定します。
2. YouTube URLを入力し、AI文法解析のON/OFFを選んで「読み込む」を押します。英語の自動字幕がある動画が対象です。
3. 再生しながら字幕と辞書を確認します。字幕のクリックやドラッグで調べる対象を選択できます。
4. 辞書の星で単語をお気に入りに、シークバー左のしおりで再生位置を保存します。履歴・お気に入りから後で復習できます。

自動字幕やAI解析には誤りが含まれることがあります。語別時刻がない字幕では、発話位置への移動に推定時刻を使います。

## データの保存

AI文法解析をONにすると、字幕のテキストを選択した解析サービスへ送信します。OFFの場合はAIへ送信しません。APIキーはmacOSのKeychainに保存します。

標準の保存先は`~/Library/Application Support/YouTubeEnglishStudy/`です。動画キャッシュの容量・保存先は設定で変更できます。キャッシュを削除しても履歴・お気に入り・辞書データは残ります。

タイムスタンプは最大1000件で、上限を超えると古い記録から削除します。動画を閉じた位置は動画ごとに最新の1件を保持します。お気に入りを解除すると、その単語に関連付けた出現位置も削除されます。

## ビルド

Swift 6以降とmacOS SDKを含むXcodeまたはCommand Line Toolsを用意します。

```sh
git clone https://github.com/Dotinkasra/Subritz.git
cd Subritz
./scripts/build.sh
open dist/Subritz.app
```
