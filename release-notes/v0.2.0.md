## changelog

- 「上級者モード」の名称を「イマージョンモード」に変更。
- 映像を非表示にした状態で再生・一時停止をクリックした際、マスクが透けて映像が見える問題を修正。
- 辞書カラムの表示領域とスクロールを整理し、単語を切り替えた際に表示位置をリセット。

## new feature

- **お気に入り単語のエクスポート**：テキスト・CSV形式に対応。登録日の範囲や最新の件数で対象を選択でき、登録日時・動画URL・タイトル・出現時刻のメタデータも追加可能。日本語語義や辞書の詳細定義は含めません。
- **字幕のスクロール固定**：ピンボタン、または字幕行の余白のダブルクリックで自動スクロールを停止・再開。固定中の行をオレンジの枠で表示します。
- **日本語辞書のマスク表示**：お気に入り単語と、イマージョンモード中に選択した単語・表現の日本語語義・詳細定義をグレーのマスクで非表示に。クリックや表示ボタンで切り替えられ、別の単語を選択すると再び非表示になります。
- **Cambridge Dictionary検索**：動画再生画面とお気に入りの辞書から英英辞書を開けます。動画の辞書ヘッダーに「調べる」ボタンを追加し、単語がない区間では検索ページを表示します。
- **辞書を開くブラウザの選択**：システムのデフォルト・インストール済みブラウザ・アプリ内ポップアップに対応。ブラウザ候補にはアプリアイコンを表示し、同じブラウザの別バージョンも選び分けられます。
