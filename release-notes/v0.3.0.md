## changelog

- 保存済みタイムスタンプを動画ごとにまとめ、選択した動画の詳細に各タイムスタンプを一覧表示するようにしました。
- 字幕の表示調整を高速化。YouTubeの通常字幕表示では画面内の行を再利用し、長い動画の終盤でも文字数変更による負荷を抑えます。
- 元の短い字幕の区切りをまたいで表示行を再構成。1行の文字数を最大にすると画面幅いっぱいを使い、単語の時刻・検索・辞書・文法との対応を維持します。
- アクティブな字幕行の句読点をテキストとして描画し、無効なボタンの文字色が適用される問題を解消しました。
- 視聴時間ボタンを「閉じる」の右へ移動し、履歴とお気に入りをグループ化。AI文法解析の状態はフッターに表示します。
- トップ画面と表示調整の説明文を整理し、設定画面のバックアップ・音声認識・キャッシュ・辞書の説明を情報ボタンにまとめました。

## new feature

- **英語の視聴時間**：英語字幕のある動画を音声ありで聞いた時間と、音声認識で検出した英語区間を記録。年・月・週・日ごとのグラフで振り返れます。
- **バックアップと復元**：iCloud Driveなどの選択フォルダへ、学習データ・設定・カラム配置を保存。自動保存・手動保存・復元に対応し、復元前の状態も退避します。キャッシュ・辞書データ本体・音声データ・APIキーは含みません。
- **字幕の表示調整**：フッターの「表示調整」から文字サイズ・1行の文字数・行間を変更。YouTubeと音声認識で別々に記憶し、ポップアップ内のリセットボタンから確認後に初期値へ戻せます。
- **YouTube字幕の手動閲覧**：上下にスクロールすると自動追従を一時解除。字幕カラム下部の↑／↓ボタンで現在位置へ戻り、追従を再開できます。

## support

- macOS 15.0以降
- Intel / Apple Silicon（Universalアプリ）
- リアルタイム音声認識は、macOS 26以降のSpeechTranscriber対応Macで利用できます。
